Cài GốcPro

Thêm icon ra màn hình chính iPhone / iPad — mở app toàn màn hình, không cần App Store.

  1. Mở trang này bằng Safari (không dùng Chrome).
  2. Bấm nút Cài đặt hồ sơ bên dưới.
  3. Vào Cài đặt → Hồ sơ đã tải về → Cài đặt.
  4. Icon GốcPro sẽ hiện trên màn hình chính.
Cài đặt hồ sơ

iOS sẽ hỏi xác nhận. Hồ sơ chỉ thêm lối tắt web, không đọc dữ liệu máy.
